# Gradient Descent Experiments

A numerical study of gradient-based optimization algorithm using Python and Jupyter Notebook. This project explores the mathematical foundations and numerical behavior of gradient-based optimization algorithm through implementation, experimentation, and visualization.

## Objectives

- Implement gradient-based optimization algorithm for numerical optimization.
- Investigate how stability, convergence speed, scalability and runtime are determined by hyperparameter (step size, decay rate etc), curvature of the objective function and dimension of the optimization problem.
- Visualize objective functions and optimization trajectories.
- Compare numerical behavior with theoretical expectations.
